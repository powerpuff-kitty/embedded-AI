# Companion pipelines and toolkits

These records describe complete systems or integration libraries, not individual tiny neural networks. They use the shared catalogue schema with `kind: pipeline` or `kind: toolkit` and are indexed alongside models and primitives. Their model size fields remain null; dependencies and map/scene memory belong in notes or future benchmarks.

See [vision, video and 3D guide](../docs/VISION-VIDEO-3D.md).
